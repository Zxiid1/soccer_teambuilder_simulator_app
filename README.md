This is an app that lets you make your own soccer team by buying players within a budget in the transfer market. After finalizing the team,
you can simulate a league season by using a specialized UI that shows the league table every matchweek along with the stats of your team
and the scorelines for each game. The results of the games are decided by RNG, but higher attack and defense stats allow a better chance 
for team success and a higher probability of winning the simulated league. This project was coded using python with the Flask web framework.

How to use the app:

1. Download the zip file of the code folder
2. Extract the zip folder
3. Open the folder in a code editor like VS Code
4. Run the app.py code and click the localhost URL
